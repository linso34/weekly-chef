# WeeklyChef PWA

Vite + Tailwind v4 + vanilla JS. No backend; data lives in IndexedDB/localStorage.

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # outputs dist/
    npm run preview    # serve the production build (service worker only runs here)

Set your Gemini API key in Settings, then use "Test connection".
Bump `VERSION` in `public/sw.js` on each release.
